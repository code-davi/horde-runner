# 0015 — Direção de arte adiada para o subprojeto 2

**Status:** aceito · 2026-10-03

## Contexto
O autor quer pesquisar assets gratuitos e definir as animações com o núcleo já rodando. Animações simples demais dão aspecto de "jogo de flash".

## Decisão
O subprojeto 1 usa formas geométricas. A direção de arte é definida em um brainstorming próprio no subprojeto 2.

## Consequências
