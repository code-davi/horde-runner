# 0006 — Heróis são a vida; chefão encostar é fim de jogo

**Status:** aceito · 2026-10-03

## Opções
A) contato troca monstro por heróis · B) qualquer toque = fim de jogo · C) híbrido.

## Decisão
C: monstros comuns e fortes removem heróis ao encostar (e somem); o chefão encostar encerra a partida. A partida também termina quando a tropa chega a zero.

## Consequências
Portões viram decisões de sobrevivência; cada chefão é um clímax.
